---
description: Run the EduAgent full stack application (Frontend + Backend)
---

This workflow starts both the backend server and the frontend client for EduAgent.

1. Start the Backend Server
   - Open a terminal
   - Navigate to the server directory
   - Install dependencies (if not already installed)
   - Start the server

```bash
cd server
npm install
npm run dev
```

2. Start the Frontend Client
   - Open a NEW terminal
   - Navigate to the project root
   - Install dependencies (if not already installed)
   - Start the development server

```bash
npm install
npm run dev
```

3. Access the Application
   - Open your browser to http://localhost:5173
